음성 테스트 VoxCPM

VoxCPM은 OpenBMB의 오픈소스 음성 합성(TTS) 모델입니다. 몇 초짜리 참고 음성을 넣으면 그 목소리로 원하는 문장을 읽어 줍니다. inkinno에서는 애니메이션 내레이션 가안을 만드는 데 테스트했습니다. 아래는 VoxCPM2 기준 간단 정리입니다.

1. 준비

  • NVIDIA GPU(CUDA) 환경 권장. CPU는 매우 느립니다.
  • Python과 CUDA 버전에 맞는 PyTorch를 먼저 설치합니다.
  • 참고 음성: 잡음 없는 한 사람 목소리 WAV 파일.

2. 설치

pip install voxcpm

처음 실행할 때 Hugging Face에서 모델(openbmb/VoxCPM2)을 자동으로 내려받습니다. 수 GB라서 첫 실행은 오래 걸립니다.

3. 기본 사용법

import soundfile as sf
from voxcpm import VoxCPM

model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)
sr = model.tts_model.sample_rate   # VoxCPM2 = 48000 Hz

wav = model.generate(
    text="안녕하세요, inkinno 음성 테스트입니다.",
    reference_wav_path="ref.wav",   # 따라 할 목소리
    cfg_value=2.0,                  # 높을수록 문장·목소리를 더 강하게 따름
    inference_timesteps=10,         # 높을수록 품질↑ 속도↓
)
sf.write("out.wav", wav, sr)

4. 설정 값

reference_wav_path복제할 목소리. 빼면 기본 목소리로 읽습니다.
cfg_value2.0 전후에서 시작. 너무 높으면 소리가 딱딱해집니다.
inference_timesteps10이면 빠르고 충분히 쓸 만합니다. 품질이 아쉬우면 올려 보세요.
load_denoiser참고 음성이 이미 깨끗하면 False로 두어 로딩을 줄입니다.

5. 활용 팁

  • 여러 번 생성해서 고르기 — 같은 문장도 실행할 때마다 결과가 다릅니다. 문장마다 2~3개를 만들어 가장 깨끗한 것을 고릅니다.
  • 짧게 끊긴 결과 다시 만들기 — 출력 길이가 문장 길이에 비해 너무 짧으면 중간이 잘린 것입니다. 길이를 확인해 자동으로 다시 생성하면 편합니다.
  • 참고 음성 이어 붙이기 — 같은 사람의 짧은 녹음 여러 개를 하나로 이어 붙여 참고 음성으로 쓰면 목소리가 더 안정됩니다.
  • 문장 단위로 나누기 — 긴 대본은 문장별로 나눠 만들고 편집 프로그램에서 이어 붙입니다.
  • 권리 확인 — 다른 사람 목소리를 복제할 때는 반드시 본인 동의를 받으세요.
